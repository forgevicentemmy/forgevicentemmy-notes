# forgevicentemmy-notes

Open-source maintainer · Rust and cargo · archiving old docs

拿来练手的小仓库

## 用法

```bash
cat data.txt | node index.js
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 为什么写

现有的工具都太重，就想要个能管道拼接的小东西。

## 安装

```bash
git clone https://github.com/USER/forgevicentemmy-notes.git
cd forgevicentemmy-notes
npm install
```
